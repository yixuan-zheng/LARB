# PACE repair round

This round has independent math and agent jobs. Reuse the existing model pins, vLLM 0.11.2 environments and Slurm account. Use new PACE scratch directories and retain the previous run artifacts. CPU regression checks run on PACE.

| Track | Proposed ceilings | Evidence required |
|---|---|---|
| Omni-MATH | One L40S, four slots, three hours. The prior four-slot capacity probe measured 198.5 output tokens/s, so 1.38M maximum grid output tokens correspond to about 1.93 hours of continuous decode before startup and batch tails. | Run the original frozen 192 solves before accessing the selector. Write per-budget counts and mean realized tokens independently of selector results. Then run three constrained-choice calls before evaluating the full selection replay. Charge input, generated tokens and observed latency separately. Compare accuracy versus realized work against the four fixed budgets and the histogram-matched shuffle using the Stage B analysis. |
| Local τ²-bench | One L40S plus one A40, up to one hour each. Both customer checkpoints run sequentially on the A40. | Keep the original six official task prompts. On both customer models run the same identity/lookup probes and the same scripted multi-turn histories with critical constraints. Inspect paired responses for facts, goal, and hard constraints. Require an exact 2,048-token forced close, valid parsed name/arguments/ID, and a successful follow-up after the mock result. |

The math harness catches `asyncio.TimeoutError` from Python 3.10's `asyncio.wait_for`, aborts that request, and uses the recorded fallback. Run `python -B -m unittest discover -s . -p test_math_timeout.py` using the pinned PACE Python. Copy the original frozen math manifest and analysis script to the new job directory, and point its `repo` link to the original read-only source checkout. Hash the frozen inputs before submission. Compare valid label rate and budget mix before interpreting performance.

This controlled fixture tests whether the interface survives a binding cap. Natural policy behavior is assessed separately.
