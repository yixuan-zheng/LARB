[Temporal Predictors, §§3–4](https://arxiv.org/html/2511.14773v1) studies eventual correctness from fixed reasoning positions on difficulty-balanced numeric MATH, with Qwen3-8B and Llama 3.1-8B, greedy 512-token decoding, and ten checkpoints from 4 to 512. Its accuracy and AUROC curves use changing survivor populations. [Reasoning Models Know When They’re Right, §3](https://arxiv.org/html/2504.05419v1) instead labels intermediate answers within reasoning chunks, represents each at the final layer's last chunk token, and fits a weighted two-layer MLP, with a linear special case. This supports correctness probing and calibration diagnostics. It supplies a different label and architecture from the replication here. [Learning How Hard to Think, §3](https://arxiv.org/html/2410.04707) learns budget-to-budget expected reward increments from sampled outcomes, using a query-state MLP or LoRA. We borrow the difference in expected reward and retain the Temporal linear architecture. Extending one trajectory from 4K to 8K differs from buying another best-of-k sample.

## 1. Minimal correctness replication on Qwen3-4B

Start with the 115 eligible saved Week 6/7 trajectories, using the single archived 8K-policy outcome per trajectory as the final-correctness label. Preserve the normal-completion and boxed-integer grader. Extract at the paper's positions 4, 8, 16, 32, 64, 128, 192, 256, 384, and 512, plus prompt-only t=0 and the LARB-specific t=4096. Treat the first generated opener as part of the existing token budget. The constant set of 4K survivors makes the temporal curve interpretable within that selected population. Report its selection boundary explicitly.

Use the upstream representation and PCA/logistic probe. Freeze five question-grouped folds based on stable question IDs, keeping both prefix seeds together. Check normalized cross-cohort overlaps and group any duplicate questions together. Compare t=4 and t=4096 to t=0 on identical held-out rows as prespecified contrasts. Report accuracy, AUROC, class prior, held-out counts and a question-cluster uncertainty interval. If reporting probabilities, include Brier score and note that class-balanced logistic outputs can be miscalibrated. Treat the other checkpoints as a descriptive temporal curve. Fit PCA and all probe parameters solely on each training fold. If a training split lacks a class, report it as unevaluable and preserve counts.

This is a methodological replication on LARB's pinned 4B model, sampled AIME traces and 8K-policy labels. Reproducing the paper's numerical result would require its original numeric MATH selection, Qwen3-8B checkpoint, greedy generation and original 80/20 evaluation. The released metadata and metrics do not supply reusable Qwen3-4B activations. No new decoding is needed for this first LARB replication.

## 2. Controlled adaptation to continuation value

Use the same encoder, final-layer pooling, PCA and L2 logistic form. On each complete Experiment 2 checkpoint, fit two logistic heads to the short and long success counts. Expand each count into success/failure rows or use equivalent frequency weights. Fit PCA once per representation on distinct training checkpoints, before expansion. Use ordinary binomial weighting for these probability heads to preserve the empirical success rate, with the same fixed C and solver. Predict p8 minus p4 from the two estimated probabilities. Keep negative values. This changes supervision and the number of heads, with the feature extractor and linear head class held fixed.

Compare three prespecified controls on the same question folds and complete coverage:

1. **Question only.** Last saved prompt-token state from the same Qwen3-4B model. Both seeds share the identical input state.
2. **Checkpoint state.** The final reasoning token at 4K, a minimal state readout motivated by the intermediate-answer work. Use the same two-head fit.
3. **Paper representation.** Mean of the final four reasoning-token states at 4K, with the same two-head fit. Include a training-fold mean arm-rate baseline for reference.

Primary comparison is paper representation versus question-only at a fixed 29-extension budget over the 58 eligible prefixes. Use out-of-fold predictions, uniform cutoff ties and a question-grouped interval that refits the pipeline within resampled training groups while keeping held-out questions disjoint. Report held-out arm log loss/Brier scores, delta error and rank association, and within-question ranking where the two seed estimates differ. For an honest allocation estimate, freeze a deterministic split of the eight suffix seeds per arm into two halves. Use one half for training supervision and the other for policy evaluation. Swap halves as a prespecified sensitivity. Never treat suffix draws or checkpoint tokens as independent questions. Report label uncertainty and coverage, and interpret both weak and inconclusive results in light of only 29 question groups and noisy per-prefix estimates.

A useful continuation probe must improve held-out fixed-budget allocation over question-only. A correctness-probe result alone does not answer that question. Extract features before the outcome join.
