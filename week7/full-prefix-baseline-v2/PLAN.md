# Stage 1 full-prefix prediction baseline

Use one independent inference request per packet. Lock the selected model revision, engine or API configuration, output budget, and response contract after synthetic mechanics checks and before any real forecast. Both arms use the same prompt and settings. Question-only observes the question once per eligible question and reuses that forecast across seeds. Full-prefix observes the original question and all 4,096 saved reasoning tokens decoded with the pinned generator tokenizer. Preserve decoding exactly. Opaque IDs are local bookkeeping, excluded from API requests. No answer keys, suffixes, metadata, old predictions or outcomes enter the request. Verify the selected reader and its output contract on synthetic cases before running the frozen batch. No unfavorable forecasts are replaced. Transport retries can resume unrecorded cases with the same settings. Preserve semantic failures and halt on them.

All cases are retrospective development data. Week 6 uses 28 extensions over 57 eligible prefixes, and Week 7 uses 29 over 58. Rank by P(WC) − P(CW), with uniform fractional ties. Assess realized accuracy, gains and losses, ranking of discordant seeds, joint Brier score, per-class probability reliability in fixed 20-point bins, and gain AUC. Report reader usage and wall time descriptively. The primary effect is pooled accuracy lift at the prespecified within-cohort extension counts, with per-cohort effects shown. Bootstrap 10,000 samples of questions, keeping seeds together and resampling separately in each cohort. Apply each cohort's half-allocation rule within each resample. Compare realized labels and distinguish these from the expectation over repeated suffix samples.

Proposed practical minimum: four additional expected correct answers across the 115 eligible prefixes (3.48 percentage points), roughly two per cohort. Advance to Stage 2 if the point estimate reaches that minimum, the pooled 95% interval has a positive lower endpoint, and both cohort point estimates are positive. Fail to show a worthwhile effect if the pooled interval upper endpoint is below the practical minimum. Other results are inconclusive. Freeze this decision rule before outcome joining. This is a practical threshold, not a claim of power. For illustration, 10–20% paired disagreement would give a roughly 6–8 percentage-point 95% half-width under independent pairs and fixed allocations. Question clustering and rank recomputation can change precision. Wide intervals should produce an inconclusive result. Stage 1 provides retrospective evidence. A protected validation needs fresh question groups.

Inspect forecast notes after sealing and scoring. Review fixed-rank examples of helped and harmed allocations within each cohort. Use existing generator traces only.
